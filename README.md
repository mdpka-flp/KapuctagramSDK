# KapuctagramSDK 💬

---

**KapuctagramSDK** — библиотека для .NET (C#), 
реализующая протокол мессенджера с обменом текстовыми сообщениями и файлами.
SDK позволяет подключаться к серверу, авторизовываться, управлять чатами, 
отправлять и получать сообщения и файлы.
